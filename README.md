# soczewki-mikrofluidyczne
Notebook soczewki_w_mikrofluidyce.nb składa się z trzech modułów, pozwalających na zaprojektowanie soczewki oraz zoptymalizowanie jej położenia względem kanału głównego, przez który przepływają komórki bądź krople z komórkami oraz względem końcówki światłowodu do którego wpada fluorescencja pochodząca z komórek.
